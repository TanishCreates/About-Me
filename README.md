# Tanish Saini — Personal Portfolio

A dark, editorial-style personal website combining a developer portfolio with music, media and social links.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Customize first

1. Add your photo to `images/profile.jpg`.
2. Update the Instagram, Spotify and GitHub URLs in `js/script.js`.
3. Update the currently watching title/description in `js/script.js`.
4. Replace the visual artifact placeholders with your own images.
5. Change the contact email in `index.html`.

## Stack

HTML + CSS + JavaScript.
